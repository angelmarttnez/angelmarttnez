🍯 Proyecto destacado: FlyPaper

Honeypot web de alta interacción, desplegado en producción en Hetzner Cloud, con IA integrada para análisis de ataques. Construido replicando vulnerabilidades reales (SQLi, XSS) como cebo, para estudiar el ataque desde ambos lados: cómo se explota y cómo se detecta.


Stack: Python · Flask · SQLite · Gunicorn · Docker Compose · Claude API · Chart.js
Detecta automáticamente 7 tipos de ataque (SQLi, XSS, Path Traversal, Fuerza Bruta, CSRF, Scanner, SSRF) con niveles de gravedad
Dashboard privado con gráficas, filtros, geolocalización de atacantes y resúmenes diarios generados por IA
Sistema CTF integrado, exportación forense en CSV, bloqueo activo de IPs


🔗 github.com/angelmarttnez/FlyPaper

🐍 PyNer

CLI en Python que analiza código .py con LLMs (Groq/Anthropic): detecta inputs sin sanitizar, secrets hardcodeados y malas prácticas de autenticación, sugiriendo correcciones en formato diff. Mapeo opcional a CWE.
